STUDENTHUB - LEARNING MATERIALS UPDATE

Open index.html in a modern browser. Keep style.css beside index.html.
The Learning materials page contains 8 PDF textbooks in:
materials/textbooks/

The site uses relative file paths. To publish it, upload the complete StudentHub
folder (including the materials folder) to your static hosting provider. Do not
upload only index.html and style.css or the PDF links will not work.

IMPORTANT: The supplied textbooks contain copyright notices. Confirm you have
the right to redistribute each PDF publicly before publishing the files online.

This is a static website. It does not yet have an online admin upload system;
adding new materials means placing the files in the folder and adding entries
to the learningMaterials list in index.html.
